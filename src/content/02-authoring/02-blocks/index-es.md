# Bloques

Los bloques de contenido que open-docs añade sobre Markdown, implementados
como etiquetas de [Markdoc](https://markdoc.dev/). Úsalos cuando el texto y
los bloques de código simples no bastan.

{% cards %}
{% card title="Callouts y pestañas" href="/es/authoring/blocks/callouts-and-tabs" icon="💡" %}
Resalta notas y agrupa instrucciones alternativas.
{% /card %}
{% card title="Pasos y tarjetas" href="/es/authoring/blocks/steps-and-cards" icon="🔢" %}
Procedimientos numerados y tarjetas de enlace como estas.
{% /card %}
{% card title="Más bloques" href="/es/authoring/blocks/more-blocks" icon="🧩" %}
Acordeones, distintivos, árboles de archivos e incrustación de vídeos.
{% /card %}
{% card title="Bloques de blog" href="/es/authoring/blocks/blog-blocks" icon="📰" %}
Imágenes hero, avatares, citas destacadas y galerías.
{% /card %}
{% card title="Código y diagramas" href="/es/authoring/blocks/media/code-and-diagrams" icon="💻" %}
Nombres de archivo, resaltado de líneas, diffs y diagramas de Mermaid.
{% /card %}
{% card title="Capturas de pantalla" href="/es/authoring/blocks/media/screenshots" icon="🖼️" %}
Imágenes enmarcadas con variantes para modo claro y oscuro.
{% /card %}
{% /cards %}

Las dos últimas viven en una subsección **Media** anidada. Esta página y sus
hijas son la forma en que esta documentación demuestra el
[anidamiento de varios niveles](/es/navigation/folder-derived-nav#anidamiento) de la barra lateral.
