# Redacción

open-docs renderiza Markdown estándar, además de unos cuantos extras añadidos
por encima mediante [Markdoc](https://markdoc.dev/): callouts, pestañas,
capturas, código con resaltado de sintaxis y diagramas de Mermaid.

Nunca estás obligado a usar los extras. Un archivo `.md` plano con encabezados,
listas, enlaces y bloques de código se renderiza por sí solo. Recurre a los
bloques personalizados cuando la prosa por sí sola no basta.
