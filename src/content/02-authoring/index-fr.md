# Rédaction

open-docs affiche le Markdown standard, avec en plus quelques extras ajoutés
par-dessus via [Markdoc](https://markdoc.dev/) : callouts, onglets, captures
d'écran, code coloré et diagrammes Mermaid.

Vous n'êtes jamais obligé d'utiliser ces extras. Un simple fichier `.md` avec
des titres, des listes, des liens et des blocs de code s'affiche tout seul.
Recourez aux blocs personnalisés quand le texte ne suffit plus.
