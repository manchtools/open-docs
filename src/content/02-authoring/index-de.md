# Inhalte erstellen

open-docs rendert standardkonformes Markdown, dazu ein paar Erweiterungen
obendrauf über [Markdoc](https://markdoc.dev/): Callouts, Tabs, Screenshots,
syntaxhervorgehobenen Code und Mermaid-Diagramme.

Sie müssen die Erweiterungen nie verwenden. Eine schlichte `.md`-Datei mit
Überschriften, Listen, Links und Code-Blöcken rendert für sich allein.
Greifen Sie zu den eigenen Blöcken, wenn Fließtext allein nicht ausreicht.
