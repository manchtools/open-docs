# v0.3.0

The release that added languages and search-engine support.

- Multi-language via a `-de` filename suffix. The default language
  stays unprefixed, untranslated pages fall back, search works per
  language, and a language switcher and `hreflang` alternates come
  along. The bundled docs ship in English, German, French, and
  Spanish; the interface itself speaks 44 languages.
- Per-page titles, descriptions, canonical and Open Graph tags,
  `sitemap.xml`, `robots.txt`, and an `llms.txt` index.
- Columns and grid layout blocks, footer meta pages for legal notices,
  GitHub-style diff gutters, OS-aware screenshot window chrome, and a
  click-to-zoom lightbox for images and diagrams.
