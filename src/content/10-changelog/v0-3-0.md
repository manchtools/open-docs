# v0.3.0 — multi-language, SEO, and layout blocks

The feature release that internationalized open-docs:

- Multi-language via a `-de` filename suffix: default language stays
  unprefixed, untranslated pages fall back, per-language search, a
  language switcher, and `hreflang` alternates. The bundled docs ship in
  English, German, French, and Spanish; the interface chrome speaks 44
  languages.
- SEO and AI discoverability: per-page titles, descriptions, canonical
  and Open Graph tags, `sitemap.xml`, `robots.txt`, and an `llms.txt`
  index.
- Columns and grid layout blocks, footer meta pages for legal notices,
  GitHub-style diff gutters, OS-aware screenshot window chrome, and a
  click-to-zoom lightbox for images and diagrams.
