# v0.6.1

A patch for the bundled documentation and two rendering fixes.

- Fixed a hydration failure on every page with footnotes: the generated
  footnote items were paragraph-wrapped into invalid HTML. Checkboxes
  and other void elements also no longer log console warnings.
- Documentation sanity sweep across all four languages: the Authoring
  section is reordered (Existing markdown now sits right after the
  Markdown basics), stale build-era wording is gone, and new features
  are cross-linked where readers look for them.
- Every block now has a live example, including task lists, footnotes,
  and the hero with overlapping avatar on the Blogging page.
