# v0.4.1

A patch for log readability when several containers run on one host.

- Every boot prints what is being served:
  `content source: /content (27 pages, languages: en)`.
- Serving the bundled documentation is described neutrally, with a hint
  on how to mount your own content.
- A mounted but empty `/content` produces a clear warning. Docker
  silently creates missing host paths as empty directories, which made
  this case easy to misread.
