# v0.4.1 — clearer container logs

A small patch focused on log ergonomics for multi-container fleets:

- Every boot prints a source-of-truth line:
  `content source: /content — 27 pages, languages: en`.
- Serving the bundled documentation is described neutrally, with a hint
  on how to mount your own content.
- A mounted-but-empty `/content` warns loudly about Docker silently
  creating missing host paths as empty directories.
