# v0.4.0

Content is no longer compiled. The container parses and validates the
Markdown when it starts, in seconds and on about 100 MB of memory, and
renders pages on the server.

- Mounted content serves in under two seconds. 256 MB hosts work.
- `PUBLIC_*` variables, content tokens, and `theme.css` are read at
  runtime. Rebranding is a restart, not a rebuild.
- Validation stops the container with file and line numbers: unknown
  tags, missing required attributes, dead internal links, missing
  screenshot files. Fenced examples are always literal.
- Search is indexed shortly after boot, per language.
- `BASE_PATH` deployments work end to end for the first time.
- Mounted static files win over precompressed variants in every
  browser, and icons with a `-dark` variant follow the theme toggle.
