# v0.4.0 — the runtime content pipeline

Content stopped being code. Markdown is parsed and validated when the
container starts — seconds, on about 100 MB of memory — and pages render
on the server.

- Mounted content serves in under two seconds; 256 MB hosts work.
- Every `PUBLIC_*` variable, content tokens, and `theme.css` are read at
  runtime: rebranding is a restart, not a rebuild.
- Validation fails the boot with file-and-line errors: unknown tags,
  missing required attributes, dead internal links, missing screenshot
  files. Fenced examples are always literal.
- Search is indexed moments after boot, per language.
- `BASE_PATH` deploys work end to end for the first time.
- Operator statics win over precompressed variants in every browser, and
  icons with a `-dark` variant follow the theme toggle.
