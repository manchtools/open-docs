# v0.6.4

Pages now ship Schema.org structured data for richer search results.

- Every page carries a JSON-LD graph: an `Organization` and a `WebSite`,
  plus a `BlogPosting` on a dated post — its headline, author, publish
  date, and cover image. Search engines can build article rich results and
  a clearer site identity from it, beyond the basic meta tags.
- It is emitted only when `PUBLIC_SITE_URL` is set, so every node has an
  absolute id, matching the canonical and Open Graph tags.
- Author text is escaped for safe embedding, and the block is inert data
  (`application/ld+json`, never executed), so it carries no script and needs
  no Content-Security-Policy exception.
