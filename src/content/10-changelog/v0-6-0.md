# v0.6.0

Markdown written for GitHub or VSCode now renders without rewriting.

- Relative links such as `./guides/setup.md` or `../intro.md#section`
  resolve against the linking file at render time. Source files stay
  untouched, so editor navigation keeps working.
- `README.md` acts as the folder page when no `index.md` exists.
- Images referenced next to the markdown are served from the content
  folder and render inline through the screenshot frame, in its plain
  variant; the `{% screenshot %}` block keeps the window chrome. Web
  image URLs display the same way.
- Task lists (`- [ ]`, `- [x]`) render as checkboxes.
- Footnotes (`[^1]`) become numbered superscript links with their
  definitions listed at the end of the page.
- HTML comments are stripped so review notes never reach readers.
- Documented contracts: inline HTML is never rendered, bare URLs stay
  plain text, headings use `#` syntax. A new "Bring existing markdown"
  page covers all of it in four languages.
