# v0.6.3

A security pass over everything that turns author content into markup.

- Link targets are scheme-checked. A `javascript:`, `data:`, or
  `vbscript:` URL in a markdown link, `{% card %}`, `{% avatar %}`, or
  `{% quote %}` renders as an inert link instead of running on click. Video
  embeds reject any non-`http(s)` URL for the same reason.
- Inline-SVG icons (`icon:` frontmatter and `{% card icon %}`) are
  validated against a presentational allow-list at startup. Anything with a
  script, an event handler, or an external reference fails the boot rather
  than reaching a reader through inline HTML.
- The Pagefind and content-asset routes resolve paths through a
  symlink-aware guard, so a planted symlink can't read files outside the
  served directory.
- `sitemap.xml`, `robots.txt`, and `llms.txt` escape author titles, tags,
  and slugs, so an unusual character can't break the document.
- Two source files that map to the same URL now fail the boot instead of
  one silently shadowing the other.
