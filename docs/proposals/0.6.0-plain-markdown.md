# Proposal: plain-markdown compatibility (0.6.0)

**Status:** draft; task lists already implemented on the branch
**Goal:** markdown written for other tools (GitHub READMEs, VSCode
conventions, existing doc folders) renders correctly when pointed at
open-docs, without rewriting a single line. BYOMD stays the pitch.

## Verified gaps (tested against a naive corpus)

1. **Relative links.** `[setup](./guides/setup.md)`, `../dir/file.md`,
   `other.md#anchor` are what editors auto-complete and validate.
   Resolve them at render time in the store, relative to the linking
   file: strip `.md`/`.markdoc`, map `index`/`README` to the folder URL,
   keep the anchor, run the result through the existing dead-link
   validation. Authors never rewrite links; site-absolute paths keep
   working unchanged.
2. **Relative images.** `![](./images/x.png)` with assets co-located in
   the content folder. Resolve the src the same way and serve
   non-markdown files from the content directory (image/asset extension
   allowlist, traversal-guarded) so a copied docs folder brings its
   images along — no move to `static/` required.
3. **Task lists.** `- [ ]` / `- [x]` → disabled checkboxes. DONE on this
   branch (store-side item transform, both tight and loose lists,
   fixture-tested). Makes the existing README claim true.
4. **Footnotes.** `[^1]` renders literally today. Implement as a source
   pass (like heading anchors): collect definitions, render references
   as superscript links and definitions as an end-of-page list.
5. **Raw HTML.** Markdoc escapes it (correct hygiene: no XSS, CSP
   intact). Add a curated allowlist rendered as real elements —
   `details`, `summary`, `kbd`, `sup`, `sub`, `br` — everything else
   stays escaped text. Document the boundary.
6. **HTML comments.** `<!-- … -->` is common in existing markdown;
   verify they never render and strip them if they do.
7. **README.md as folder index.** GitHub convention; treat it like
   `index.md` when no index exists.
8. **Autolinks.** Bare `https://…` URLs (GFM linkifies; CommonMark does
   not). Decide and document; low effort if wanted.
9. **Setext headings** (`===` underline) get no anchor ids today — the
   heading-anchor pass only reads ATX. Either support or document.

## Non-goals

Wiki-links (`[[page]]`), emoji shortcodes, definition lists, arbitrary
raw HTML execution. Tools that need them can pre-process; open-docs
stays strict-CSP and spec-lean.

## Milestones

1. Relative link + image resolution incl. content-dir asset serving,
   README-as-index (the migration blockers).
2. Footnotes; HTML allowlist; comments; autolink/setext decisions.
3. Docs: a "Bring existing markdown" page (en/de/fr/es); README claims
   audited against reality.
